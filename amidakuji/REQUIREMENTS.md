# あみだくじゲーム 要件分解表

| 項目 | 要件 | 実装方針 | 確認方法 |
| --- | --- | --- | --- |
| 作るもの | 参加を選び、3ステージを勝ち上がるあみだくじゲーム | Reactで状態遷移を管理する | 参加から結果まで通して操作 |
| 画面 | 参加確認、ステージ、案内役の会話、クリア、脱落 | 画面状態ごとに表示を切り替える。辞退時は「また次の機会に！」を表示 | 各画面遷移を確認 |
| 難易度 | 1:やさしい、2:ふつう、3:むずかしい | 成功枠を順に4/5、3/5、1/5とする | 各ステージのゴール数を確認 |
| あみだくじ | スタートする縦棒を選び、横棒を自分で追加・削除 | 5本の縦棒を使い、横棒は隣り合う棒の間に配置 | 横棒を追加し経路をたどる |
| 横棒の上限 | ステージ1は1本まで、ステージ2の記載が未確定、ステージ3は10本まで | ステージ2は中間難易度として5本までとする | 上限到達後に追加できないことを確認 |
| 勝敗 | 成功時のみ次のステージへ。失敗時は脱落 | ゴールの成否を判定し、失敗時はゲームオーバーを前面表示 | 成功・失敗双方の表示を確認 |
| 最終演出 | 最終ステージは赤く燃える雰囲気、クリア時は明るい祝福 | 最終画面に暖色演出、全クリア画面に明るい配色と再挑戦導線 | ステージ3前後の画面を確認 |
| 操作 | 参加意思、スタート棒選択、横棒編集、再挑戦 | ボタンと横棒位置のクリックで操作。キーボードフォーカスにも対応 | マウス・タッチで操作 |
| 追加機能 | 状況が分かりやすく、もう一度遊べる | ステージ進捗、残り横棒数、経路アニメーション、案内役のコメント | 進行中の表示を確認 |
| 技術 | HTML/Tailwind/JavaScript/React、Viteでビルド | Reactと既存Tailwind設定を利用。Viteの`base: './'`を維持 | `pnpm build` |
| 公開・表示確認 | GitHub Pages公開、幅375pxと1280pxで確認 | 公開用ビルドを作成し、狭い幅でも操作可能なレイアウトにする | DevToolsで両幅を確認 |

## 画面の流れ

参加確認 → ステージ1 → 案内役の応援 → ステージ2 → 案内役の応援 → 最終ステージ3 → 全クリア

各ステージの失敗はゲームオーバーへ、参加辞退は終了メッセージへ遷移する。成功枠の配分は各ステージのゴール5つに対する成功数である。
